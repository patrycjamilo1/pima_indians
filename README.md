# Pima Indians Diabetes Classification

## Overview
Comparison of classification algorithms for predicting diabetes using the Pima Indians dataset.

## Algorithms
- **LightGBM** (Best performance)
- **KNN** (High false negatives)
- **SVC** (Better than KNN, worse than LightGBM)

## Steps
1. Install: scikit-learn, LightGBM, Pandas.
2. Open `Analysis_pima_indians.ipynb`.
3. Run all cells.

## Conclusion
LightGBM performs best.
